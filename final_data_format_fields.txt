<name> : <description>

model: This is the model used to for producing labels
created_at: Datetime when processing of record was attempted
raw_output: This is the original output result returned by LLM. 
s1_r: This is output of biodiversity change question (q1) with values -1, 0, 1
s1_bio: This labels the type of biodiversity change

s2_r: This is output of biodiversity change direction question (q2) with values -1, 0, 1
s2_bio: This labels if the direction of change

s3_r: This is output of anthropogenic driver question (q3) with values -1, 0, 1
s3_bio: This labels the potentail anthropogenic driver present

s4_r: This is output of presence of link between driver and change question (q3) with values -1, 0, 1
s4_bio: This labels the confidence of if there's a link present 

pred_screening: Based on outputs of s1-s4, it produces list of a string with label ["ELIGIBLE"] or ["INELIGIBLE"]
pred_norm: Based on outputs of s1-s4, it produces string label "ELIGIBLE" or "INELIGIBLE"
